# LLM Anatomy 0.1

Интерактивный инспектор архитектуры локальных языковых моделей: Dense и MoE. Русский интерфейс, тёмная тема, дерево слоёв, карта связей, поиск тензоров, оценка VRAM.

## Запуск актуального приложения

Актуальная версия находится в `src/`: «Анатомия модели» и отдельная «3D-карта модели», светлая/тёмная тема и управление демонстрационным токеном. Требуется Node.js 20 или новее.

```bash
npm ci
npm run dev
```

Откройте адрес Vite, указанный в терминале (обычно http://localhost:5173). Для сборки:

```bash
npm run build
npm run preview
```

**Зависимости:** React 18, `@xyflow/react` 12, Vite 5. Доступ к npm нужен только для установки зависимостей React-версии. Для автономного HTML он не требуется.

## Автономные демо прежнего интерфейса

`standalone/index.html` и `llm-anatomy-demo.html` — прежние демо 2D-инспектора, **без 3D-карты и управления токеном**. Для новых возможностей используйте React-приложение выше. Автономные демо можно открыть через `file://`; требуется выбрать собственный файл модели.

Общие исправления парсера и оценки памяти попадают в автономные демо командой `npm run build:standalone`. Она генерирует `standalone/parser.js` из модулей `src/` и встраивает ресурсы в однофайловый HTML. Проверка актуальности: `npm run check:standalone`.

## Проверки

```bash
npm test
npm run check:standalone

```

## Как пользоваться

1. В левом меню выберите «Анатомия модели» или «3D-карта модели». На карте двойной клик раскрывает компонент, колесо меняет масштаб; проход токена — симуляция. Откройте собственную модель. В панели «Архитектура» нажимайте на блоки, чтобы перейти от общей схемы к отдельному слою, затем к FFN/MoE. Колесо мыши масштабирует граф; мышью его можно перемещать.
2. «Открыть модель» — выберите `.gguf`, один/несколько `.safetensors` или `config.json`. «Папка» — выберите директорию с несколькими шардированными `.safetensors` и `config.json` (если браузер поддерживает выбор папки).
3. Вкладка «Тензоры» — поиск по имени и типу; во вкладке «Память» — оценка веса модели и KV-cache для разных размеров контекста и batch.
4. «Экспорт» сохраняет сводку и метаданные в JSON.

## Поддерживаемые метаданные

- **GGUF v2/v3:** чтение заголовка, metadata KV, имён, типов и размерностей тензоров из локального файла через `File.slice()`. Не загружает гигабайты весов в RAM. До 32 выбранных GGUF-фрагментов.
- **SafeTensors:** чтение JSON заголовка, имён, форм и dtype тензоров, в том числе из нескольких шардов (до 128). При наличии `config.json` берутся гиперпараметры модели.
- **Config JSON:** гиперпараметры архитектуры; без весов список тензоров будет пустым, размер весов и возможность размещения в GPU неизвестны. Структурные параметры проверяются: счётчики слоёв/голов/экспертов — целые числа до 4096. Карта ограничена 12 000 объектов за один показ; для подробностей открывайте компоненты.

**Ограничения:** для некоторых нестандартных архитектур по одним весам невозможно гарантированно восстановить вычислительный граф или полноту MoE-параметров. При отсутствии `config.json` часть характеристик SafeTensors определяется по именам тензоров и может быть неизвестна. На вкладке VRAM оценка носит ориентировочный характер (принято, что KV-cache FP16). Реальные маршруты экспертных активаций без выполнения модели недоступны.

Приложение не выполняет inference, не читает содержимое тензорных данных и никуда не выгружает локальные файлы.

## Структура

```
llm-anatomy/
├── index.html                 # React/Vite entry
├── src/
│   ├── App.jsx                # React Flow и панели интерфейса
│   ├── parsers.js             # GGUF / SafeTensors header-only
│   ├── styles.css
│   └── main.jsx
├── standalone/
│   ├── index.html             # Автономная версия (раздельные файлы)
│   ├── app.js
│   ├── parser.js
│   └── styles.css
└── llm-anatomy-demo.html      # Автономный HTML в одном файле
```

## На какие проекты ориентировались

- [Weightless](https://github.com/kkipngenokoech/weightless) — модельные заголовки и архитектурные диаграммы.
- [Weights Viz](https://github.com/justinchuby/weights-viz) — форматы, тензоры и веса.
- [ModelMap](https://github.com/lizhaoliu/modelmap) — архитектура и оценка VRAM.
- [React Flow](https://reactflow.dev/) — граф интерфейса React.

Создано как учебный и экспериментальный прототип, без гарантии совместимости со всеми вариантами GGUF и SafeTensors.
