## Текущее поведение

Встроенных моделей и предзаполненных весов нет. До открытия GGUF, SafeTensors или config.json показывается приглашение выбрать файл. Выбранная модель хранится на уровне дашборда и используется во всех разделах. Её имя отображается в общей верхней шапке.

Проверки запускаются через `npm test`, `npm run check:standalone` и `npm run build`. Регрессионные тесты проверяют парсеры, правила привязки имён тензоров, часы анимации и оценку памяти на изолированных входных данных.

## Ограничения

Карта использует перспективную проекцию Canvas 2D. Движение токена — симуляция; живой inference не подключён. Значения весов не читаются, частицы тензоров схематические. Для неизвестных соглашений об именовании точная принадлежность тензоров не гарантирована. Проверка реальных многогигабайтных моделей, Firefox и Safari не выполнялась.
